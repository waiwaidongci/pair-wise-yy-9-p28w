# 古法蓝晒底片整理室

运行：

```bash
npm start
```

访问`http://localhost:3040`。数据保存在`data/cyanotype-negative-room.json`。

## 冲洗后流程

- **复晒不合格**：必须填写返工原因，登记后底片状态回到「冲洗中」，曝光时间、冲洗水源、存放盒位保留不变。
- **返工复验**：复晒合格后结掉全部未结返工（旧返工记录保留，只追加复验时间与结论）；复验仍不合格会再开一条返工。
- **修补**：记录缺陷、处理结果和是否处理完；提交「已处理完」会结掉此前未完的修补，原记录不覆盖。
- **入盒**：有未结返工或修补未处理完时禁止入盒，服务端返回原因。
- **交付**：有未结返工时提示先处理复验，不能交付。
- 返工、修补、工艺步骤均为追加记录，卡片展示最近一次返工和修补，统计与状态筛选始终按底片当前状态计算。
